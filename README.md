# 轻跳 1.1.0

轻量级 Android 7.0 及以上版本自动跳广告应用。**安装后开启“轻跳自动跳过”无障碍服务，即可使用内置识别，不需要添加规则。** 应用识别当前界面的可跳过按钮，优先调用控件点击，必要时使用触摸手势。整个过程在本机完成。

## 功能

- 内置简体、繁体、英文跳过文字、按钮描述、前后倒计时及明确的广告控件 ID 识别。
- 窗口打开后最多安排 6 次短时复查，覆盖延迟出现的按钮；界面事件合并处理，静止页面不会被无限轮询。
- 点击后复查后续关闭按钮；同一目标重试退避，30 秒内最多尝试 4 次，避免连续乱点。
- 自动排除系统设置、权限界面、桌面及锁屏状态；不把“跳过片头”“观看领金币”等操作当成广告跳过。
- 可为单个应用添加文字、控件 ID 规则；对无法暴露按钮的页面，可绑定页面类名和屏幕百分比坐标。
- 可排除指定应用。泛用的“关闭”识别默认关闭，可手动开启。
- 扩展识别“跳过”按钮默认开启，可覆盖未标注广告的页面，也可能跳过新手引导；如不需要可在“高级设置”中关闭。
- 不申请网络、悬浮窗、读取媒体、开机启动或前台服务权限；不持续轮询、截屏或使用 OCR。测试框架只用于构建验证，不会打包进 APK。

## 使用

1. 按下方构建步骤生成并安装 `app/build/outputs/apk/debug/app-debug.apk`，然后打开“轻跳”。旧版用户可覆盖安装，保留设置与自定义规则。
2. 点击“打开无障碍设置”，启用“轻跳自动跳过”。
3. 返回应用，确认显示“服务已开启”。
4. 照常使用其他应用，无需在首页填写包名、坐标或下载规则。自定义规则和排除列表保留在默认折叠的“高级设置”中。

Android 13 及以上系统对侧载应用的无障碍服务可能设置额外限制，需要在系统的该应用设置中允许受限设置。具体入口依设备系统而异。

新坐标规则相对于当前窗口，兼容窗口偏移。旧版屏幕坐标规则保留原有含义，并在列表中标注“旧版”。坐标规则只在指定页面发生窗口切换时触发，30 秒内最多一次；离开页面、暂停服务或自动识别已经点击后会取消旧任务。布局变化仍可能使坐标规则失效。

内置识别会避开可识别的自愿观看奖励广告，以免丢失奖励；用户明确添加的自定义规则可覆盖这一默认行为。

## 构建

需要 JDK 17 和 Android SDK Platform 35。Gradle 8.9 由项目中的 Wrapper 下载并校验 SHA-256。设置 `ANDROID_HOME` 后，在项目根目录运行：

```powershell
.\gradlew.bat :app:assembleDebug
.\gradlew.bat :app:testDebugUnitTest
.\gradlew.bat :app:lintDebug
```

源码仓库不附带调试签名或 APK；构建后的 APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。应用包名保持 `com.qingtiao.app`，版本代码升级到 2。发行版本需要自行配置签名；更换签名后不能直接覆盖之前的调试版。

部分 Windows 构建工具在中文目录下运行单元测试时会出现 `ClassNotFoundException`；把项目复制到纯英文路径后可正常运行测试。APK 构建不受此问题影响。

## 能力边界与隐私

无障碍服务无法读取某些游戏、SurfaceView、图片绘制的按钮或受保护窗口；这些页面可能需要额外适配，也可能完全无法自动处理。默认识别无需用户编写规则，但不能保证每个应用、每个版本的广告都可跳过。规则、最近应用包名/页面类名及点击次数只保存在设备本地，应用没有网络权限。

项目包含纯 Java 匹配测试和 Robolectric Android 框架模拟测试，覆盖默认无规则运行、延迟控件、点击冷却、手势兜底、窗口偏移、误点保护、定时任务停止、节点回收和首页流程。模拟测试不能替代手机上的覆盖率、耗电和内存实测，目前未连接 Android 设备。

本项目为独立实现，没有包含所附“李跳跳” APK 的反编译代码或资源。
